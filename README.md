## What this entry does

This is an entry for the make.fun bounty "Fortune Cookie for the Liquidated Trader". The task is to write a single fortune-cookie line for a crypto trader who has just been liquidated — plain text, no more than 20 words.

The fortune in this entry is 17 words and 83 characters long:

> "A wise trader once lost everything too — he is now the man selling you this cookie."

## How it works

`main.ts` reads the fortune from `fortune.txt`, resolving the file path from the module's own URL rather than from the working directory, and writes the fortune out to `/output/entry.txt`. There is no model call, no randomness, and no use of the clock — the output is fully deterministic.

## Run it

```sh
node main.ts
```

The resulting fortune is written to `/output/entry.txt`, ready to be read back as the entry output.
